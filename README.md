# Art Gallery Backend (.NET Core)

Этот проект представляет собой бэкенд для платформы цифрового искусства, разработанный для управления контентом, профилями художников и социальным взаимодействием (просмотры, лайки, комментарии, подписки).

Изначально проект был написан на Java (Spring Boot), но был полностью мигрирован на **C# (.NET 8/10)** с применением подходов Clean Architecture и Domain-Driven Design (DDD) в учебных целях.

## О проекте

Бэкенд предоставляет RESTful API для взаимодействия с клиентским SPA-приложением. Он включает многоуровневое кэширование, потоковую обработку файлов, интеграцию с AI-сервисами и безопасную аутентификацию.

### Ключевые особенности
- **Управление артами**: Загрузка, просмотр, обновление и удаление артов.
- **Тегирование артов**: Автоматическое и ручное добавление тегов для категоризации и поиска.
- **Взаимодействие с пользователями**: Лайки, просмотры и комментарии к артам.
- **Профили пользователей**: Регистрация, обновление профиля, управление социальными сетями и подписками.
- **Система рекомендаций**: Ленты артов, включая трендовые, рекомендованные и подписки.
- **Поиск**: Поиск артов по названию и тегам.
- **Надежное хранение**: Использование S3-совместимого хранилища для медиафайлов.
- **Кэширование**: Использование Redis для повышения производительности API.
- **Безопасность**: Аутентификация и авторизация на основе Keycloak.

## Технологический стек

- **Платформа**: C#, .NET 8 / 10, ASP.NET Core Web API
- **Архитектура**: Clean Architecture, Pattern Decorator
- **База данных**: PostgreSQL + Entity Framework Core (Fluent API)
- **Аутентификация**: Keycloak (`Microsoft.AspNetCore.Authentication.JwtBearer`)
- **Кэширование**: Redis (`StackExchange.Redis`), библиотека `Scrutor`
- **Хранилище файлов**: MinIO (через `AWSSDK.S3`)
- **Маппинг**: `Mapster`
- **Тестирование**: xUnit, FluentAssertions, NSubstitute, Testcontainers

## Настройка и запуск (Docker)

Проект полностью контейнеризирован. Бэкенд, база данных, кэш, Keycloak и S3 поднимаются одной командой.

### 1. Подготовка конфигурации
В корне проекта создайте файл `.env` на основе шаблона:
```bash
cp .env.example .env
```
*(При необходимости измените пароли и порты внутри `.env` файла).*

### 2. Запуск всего стека
Выполните команду для сборки и запуска инфраструктуры и C#-бэкенда:
```bash
docker-compose up -d --build
```
Это запустит: **PostgreSQL**, **Keycloak**, **MinIO**, **Redis** и сам **arts-api**.

### 3. Инициализация MinIO (S3)
После запуска контейнеров сделайте бакет для картинок публичным, выполнив команды в терминале:
```bash
docker exec -it minio /usr/bin/mc alias set myminio http://localhost:9000 minioadmin minioadmin
docker exec -it minio /usr/bin/mc mb myminio/arts-photo
docker exec -it minio /usr/bin/mc anonymous set public myminio/arts-photo
```

## Документация API и Авторизация

### Swagger UI
После успешного старта интерактивная документация со всеми доступными эндпоинтами и DTO будет доступна по адресу:
👉 **http://localhost:8081/swagger**

### Keycloak
* Панель администратора: **http://localhost:8080/admin** (Логин и пароль указаны в `.env`, по умолчанию `admin` / `admin`).
* Доступ к защищенным эндпоинтам API осуществляется через передачу валидного JWT-токена в заголовке `Authorization: Bearer <token>`.

## Тестирование
Проект покрыт двухуровневой системой тестов:
1. **Unit-тесты** (`Arts.Domain.UnitTests`): Мгновенная проверка доменных инвариантов и логики сущностей.
2. **Integration-тесты** (`Arts.Api.IntegrationTests`): Сквозное тестирование контроллеров, маршрутизации и запросов к БД. Изолированный PostgreSQL поднимается динамически перед каждым прогоном через **Testcontainers**, а Redis и MinIO заменяются на In-Memory заглушки.

Запуск всех тестов:
```bash
dotnet test
```
